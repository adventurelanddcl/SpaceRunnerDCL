# Space Runner - Project Overview

The game was developed as an obstacle course experience in **Decentraland**, featuring a central lobby, 10 progressively challenging maps, collectible gems, and a variety of hazards and interactive obstacles.

## Lobby

The game features a central lobby divided into five areas, each serving a specific purpose:

- **Middle — Start Area**
  The main player spawn area. Players can enter the game immediately through a portal leading to the first map.

- **Front — Leaderboard Area**
  Displays player rankings and special leaderboards during events.

- **Left — Information Area**
  Provides information about the game and showcases examples of the obstacles, hazards, and interactive objects players will encounter throughout the maps.

- **Right — Shop Area _(Future Development)_**
  Planned area where players will be able to exchange collected gems for Decentraland wearables.

- **Back — Events & Quests Area _(Future Development)_**
  Planned space for events and a quest system, potentially including daily, weekly, and monthly challenges. The final implementation is yet to be determined.

## Maps & Progression

The game includes **10 maps with progressively increasing difficulty**. As players advance through the maps, they encounter more challenging obstacle combinations and increasingly rare gem types.

### Collectible Gems

There are **four types of collectible gems**, distributed across the maps according to difficulty:

- **Common gems** — primarily found in easier, lower-level maps.
- **Rare gems** — found in higher-level maps with increased difficulty.
- Additional gem tiers provide progression and potential future use within the planned shop system.

### Obstacles & Hazards

The maps feature a variety of obstacles designed to test player movement, timing, and reaction speed:

| Obstacle                   | Description                                                                          |
| -------------------------- | ------------------------------------------------------------------------------------ |
| **Bounce Pad**             | Deals damage and can launch players off the map.                                     |
| **Bounce Beam**            | Deals damage and pushes/bounces players backward.                                    |
| **Swinging Hammer**        | Deals damage when it hits a player.                                                  |
| **Rotating Meteor Ball**   | A rotating hazard that deals damage on contact.                                      |
| **Falling Meteors**        | Falling projectiles that deal damage when they hit players.                          |
| **Laser Wall / Lasers**    | Laser hazards that deal damage on contact.                                           |
| **Disappearing Platforms** | Platforms that disappear after a player stands on them for a certain amount of time. |
| **Enemy Robot**            | An enemy NPC that deals damage to players on contact.                                |
| **Spike Plate**            | A floor hazard that deals damage on contact.                                         |
| **Rotating Spike Beams**   | Rotating obstacles equipped with spikes that deal damage on contact.                 |

## Assets

### 3D Models

All 3D models used in the game were created specifically during the development of the game.

### Textures

The following textures and 2D assets were used in the game:

- **Meteor Ball & Falling Meteors** — texture generated using **Google Gemini**.
- **Robot Eyes** — textures generated using **Google Gemini**.
- **Warning Line** — texture generated using **Google Gemini**.
- **Start Portal Swirl** — texture generated using **Google Gemini**.
- **Metal Ground Plate** — based on the **MetalPlates017A** material from [AmbientCG](https://ambientcg.com/view?id=MetalPlates017A), available under the **CC0 license**. The texture was subsequently edited using **ChatGPT**.
- **Space Runner Logo/Text** — created in **Inkscape** and subsequently edited using **Google Gemini**.

### Sounds & Music

- **Background Music** — generated using **Google Gemini**.
- **Gem Collection Sound** — sourced from a Decentraland Smart Items repository and used as an in-game sound effect.

## Future Development

- **Daily, weekly, and monthly quests**.
- **Special events and challenges**.
- Further expansion of the game's **progression and reward systems**.
